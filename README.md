# Stock Manager

A simple browser-based inventory management app for tracking stock items.

## Features

- Add new inventory items
- Track item names, colors, fabrics, quantities, and prices
- Search inventory by name, color, or fabric
- Edit and delete inventory items
- Identify items with low stock
- Track recent inventory activity
- Export inventory data as a CSV file
- Light and dark theme support
- Save data locally in the browser using `localStorage`

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/IMRANZZZZ/Satre.git
   ```

2. Open the project folder.

3. Open `index.html` in a web browser.

No installation or server is required.

## Usage

Use the **Add new item** form to enter product information. After adding an item, it will appear in the inventory table.

Use the search box to find items by name, color, or fabric. Your inventory data is saved in your browser and remains available when you return to the app using the same browser.

## Data Storage

This application uses browser `localStorage` to save inventory and activity data. Clearing your browser's site data may delete the saved inventory.
